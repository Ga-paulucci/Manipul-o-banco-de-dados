# 📊 Manipulação de Banco de Dados com Python

## 🎯 Propósito do Projeto
Este projeto foi desenvolvido com o objetivo de demonstrar habilidades práticas na manipulação, limpeza e estruturação de dados provenientes de bancos de dados relacionais utilizando Python. A capacidade de conectar, extrair (ETL) e tratar dados brutos diretamente da fonte é um dos pilares fundamentais para qualquer Cientista de Dados.


## 🛠️ Tecnologias e Ferramentas Utilizadas
* **Linguagem:** Python 3.x
* **Manipulação de Dados:** Pandas
* **Banco de Dados:** SQLite
* **Ambiente:** Google Colab

---

## 🚀 Principais Habilidades Demonstradas
* **Conexão e Queries:** Criação de conexões seguras com o banco de dados e execução de queries estruturadas.
* **Processo de ETL:** Extração dos dados transacionais, transformação (limpeza de nulos, conversão de tipos, junção de tabelas/JOINs) e carga em DataFrames para análise.
* **Pensamento Analítico:** Transformação de dados brutos em métricas relevantes para tomada de decisão.

---

## 📋 Estrutura do Notebook e Documentação

O arquivo `Manipulando_banco_de_dados.ipynb` está dividido nas seguintes etapas organizadas:

1.  **Configuração do Ambiente:** Importação de bibliotecas e criação da conexão com o banco.
2.  **Exploração Inicial:** Leitura das tabelas e entendimento do Schema do banco de dados.
3.  **Manipulação de Dados:** Aplicação de filtros, agrupamentos (`groupby`), agregações e cruzamento de dados (equivalente a INNER/LEFT JOINs em SQL).
